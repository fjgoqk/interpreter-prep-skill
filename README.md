# Interpreter Prep Skill

A DSH skill for preparing Chinese-English interpreting assignments. It creates an English briefing with a bilingual Chinese-English glossary, source links, and verification notes for Obsidian.

## Download

Use GitHub's Code → Download ZIP, then extract the archive. The skill is in the interpreter-prep folder.

## Install for DSH

Copy the interpreter-prep folder into the Obsidian vault's .dsh/skills/ directory, so the final path is .dsh/skills/interpreter-prep/SKILL.md. Open the vault as DSH's project and start a new session. DSH's skill discovery paths and folder format are documented in the official [DeepSeek Harness skills guide](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/skills.md).

Use /interpreter-prep or describe the assignment in natural language. See [the full usage guide](interpreter-prep/README.md).
